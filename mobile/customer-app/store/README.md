# Store listing assets (you generate the screenshots)

Play Console still needs **phone screenshots** from you. Drop files here, then upload in Play Console.

## Required uploads

| Asset | Size | File in this folder |
|---|---|---|
| High-res icon | 512×512 PNG | `icon-512.png` (generated) |
| Feature graphic | 1024×500 PNG | `feature-graphic.png` (generated) |
| Phone screenshots | min 2, JPEG or 24-bit PNG, **16:9 or 9:16**, between 320px and 3840px on each side | `screenshots/phone-01.png` … |
| 7-inch tablet (optional) | at least 1 | `screenshots/tablet-7-01.png` |
| 10-inch tablet (optional) | at least 1 | `screenshots/tablet-10-01.png` |

Do **not** include status-bar clocks with fake times, personal data, or “coming soon” placeholders. Capture real screens: home, ride quote, wallet, profile.
